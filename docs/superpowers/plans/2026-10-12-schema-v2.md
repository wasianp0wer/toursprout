# Schema v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Split an overlay's content type, location and presentation into three independent fields, so the editor can let an author choose how an item is drawn without changing what it is.

**Architecture:** `kind` (text/image/audio) says what an overlay is, `anchor` says where it is, and a new discriminated `display` union (marker/inWorld/ambient) says how it is drawn. `Credit` becomes a union so original work is attributable without a URL. A pure `migrate_v1_to_v2` upgrades existing documents, and every read path runs through it. No visible behaviour changes.

**Tech Stack:** Python 3.14, pydantic v2, FastAPI, pytest. Angular 22 (signals, standalone components), TypeScript, Vitest, three.js 0.134, mapillary-js 4.1.2, Leaflet 1.9.

**Spec:** `docs/superpowers/specs/2026-10-12-schema-v2-design.md`
**Umbrella:** `docs/superpowers/specs/2026-10-12-authoring-application-overview.md`

## Review Focus

Input classes the spec implies but which no task's happy-path tests exercise. Each has a test assigned to the task that owns the code.

1. **`schemaVersion` missing, or a future value like `3`.** A document from a newer tool must fail with a message naming the version, never be silently treated as v1 and mangled. → Task 1.
2. **Migrating an already-v2 document.** Bundles will be re-opened repeatedly; a second pass must be a no-op, not a double-migration that wraps `display` twice. → Task 1.
3. **A v1 overlay with an unrecognised `kind`.** Must raise and name the overlay id, never be silently dropped — a dropped overlay is invisible data loss. → Task 1.
4. **A stop with zero overlays.** Legal, and real: opacity seeding and inWorld filtering must not divide by zero or crash the store. → Task 1 (backend) and Task 3 (store).
5. **Boundary values.** `headingDeg` exactly `360` rejected but `359.9` and `0` accepted; `opacity` `0` and `1` accepted but `-0.1` and `1.1` rejected; `widthM` of `0` rejected. These are the values an editor's drag handles will actually produce. → Task 1.

SCHEMA_VERSION = 2


class GeoAnchor(Strict):
    """Where an overlay sits in the world.

    `altitude_m` is metres ABOVE LOCAL GROUND, not above the ellipsoid.
    Passing it raw to mapillary's `geodeticToEnu`, which wants an absolute
    height, once put the Fairfax photographs 128 m underground; the frontend's
    `geodeticAltitude()` adds the local ground reference back. The datum is
    also the one AR needs, since a phone knows its height above the pavement.
    """

    type: Literal["geo"] = "geo"
    lng: Annotated[float, Field(ge=-180.0, le=180.0)]
    lat: Annotated[float, Field(ge=-90.0, le=90.0)]
    altitude_m: float = Field(default=0.0, alias="altitudeM")


# One member today, so this is a plain alias: pydantic's `discriminator`
# requires an actual union and errors on a single type. It becomes
# `Annotated[GeoAnchor | ImageAnchor, Field(discriminator="type")]` when the
# image-anchored variant (pixel coordinates within one panorama) lands. `type`
# is already present and literal, so that change is additive.
Anchor = GeoAnchor


class MarkerDisplay(Strict):
    """A point in the scene the visitor clicks. Rendered as a mapillary-js
    SimpleMarker, and as a pin on the map."""

    mode: Literal["marker"] = "marker"
    icon: Literal["note", "photo", "audio", "place"] = "note"


class InWorldDisplay(Strict):
    """A flat plane standing in the world, drawn by three.js.

    `heading_deg` is the compass direction the face looks toward. `opacity` is
    the value the stop OPENS at; the visitor's slider moves from there.
    """

    mode: Literal["inWorld"] = "inWorld"
    opacity: Annotated[float, Field(ge=0.0, le=1.0)] = 0.7
    heading_deg: Annotated[float, Field(ge=0.0, lt=360.0)] = Field(alias="headingDeg")
    width_m: Annotated[float, Field(gt=0.0, le=200.0)] = Field(alias="widthM")
    height_m: Annotated[float, Field(gt=0.0, le=200.0)] = Field(alias="heightM")


class AmbientDisplay(Strict):
    """Heard but not seen: audio belonging to the stop as a whole."""

    mode: Literal["ambient"] = "ambient"
    autoplay: bool = True


Display = Annotated[
    MarkerDisplay | InWorldDisplay | AmbientDisplay,
    Field(discriminator="mode"),
]


def _not_blank(v: str) -> str:
    if not v.strip():
        raise ValueError("must not be blank")
    return v


class OriginalCredit(Strict):
    """The author's own work: a recording, a photograph they took.

    There is no URL to give, which is exactly why v1's single Credit shape
    could not express it and the editor could not save.
    """

    type: Literal["original"] = "original"
    creator: str = Field(min_length=1)
    license: str = Field(min_length=1)

    _check = field_validator("creator", "license")(classmethod(_not_blank))


class SourcedCredit(Strict):
    """Something obtained from somewhere citable: an archive, Mapillary, Omeka."""

    type: Literal["sourced"] = "sourced"
    source: str = Field(min_length=1)
    url: str = Field(min_length=1)
    license: str = Field(min_length=1)
    creator: str | None = None

    _check = field_validator("source", "url", "license")(classmethod(_not_blank))


Credit = Annotated[OriginalCredit | SourcedCredit, Field(discriminator="type")]


# Which presentations each content kind can currently be drawn as.
#
# A rejection here is a RENDERER limitation, not a limit of the model: the
# three axes are independent by design. Supporting world-standing text means
# flipping one cell; adding AR means adding one mode to the rows that can use
# it. Keep this a table rather than a chain of ifs so that stays true.
DISPLAY_MODES_BY_KIND: dict[str, frozenset[str]] = {
    "text": frozenset({"marker"}),
    "image": frozenset({"marker", "inWorld"}),
    "audio": frozenset({"marker", "ambient"}),
}


class Overlay(Strict):
    """One piece of placed content.

    Three independent axes: `kind` is what it is, `anchor` is where it is,
    `display` is how it is drawn. v1 welded the first and the last together,
    which made "the same photograph, as a pin instead" inexpressible.
    """

    id: str = Field(min_length=1)
    kind: Literal["text", "image", "audio"]
    anchor: Anchor
    display: Display
    title: str = Field(min_length=1)
    body: str | None = None
    media_id: str | None = Field(default=None, alias="mediaId")
    credit: Credit

    @model_validator(mode="after")
    def _payload_matches_kind(self) -> Overlay:
        if self.kind == "text" and not (self.body or "").strip():
            raise ValueError("text overlays require a body")
        if self.kind in ("image", "audio") and not self.media_id:
            raise ValueError(f"{self.kind} overlays require a mediaId")
        allowed = DISPLAY_MODES_BY_KIND[self.kind]
        if self.display.mode not in allowed:
            raise ValueError(
                f"{self.kind} overlays cannot be displayed as "
                f"{self.display.mode!r}; this renderer supports "
                f"{', '.join(sorted(allowed))}"
            )
        return self


class TourDefaults(Strict):
    """Pre-fills an OriginalCredit when the author adds their own work, so
    recording a clip does not mean retyping your own name."""

    creator: str = Field(min_length=1)
    license: str = Field(min_length=1)

```python
"""Upgrade v1 tour documents to v2.

v1 welded presentation to content type: `kind: "rephoto"` meant "an image, as
a plane standing in the world", and every other kind meant "a clickable
marker". v2 separates those, so the migration's whole job is to read the
intent v1 encoded in `kind` and write it out explicitly in `display`.

Pure: dict in, dict out, input never mutated. This module stays in the tree
after the repository's own tour is converted, because exported bundles in the
wild will still be v1.
"""

from __future__ import annotations

from copy import deepcopy
from typing import Any

from .models import SCHEMA_VERSION

_ICON_BY_KIND = {"text": "note", "image": "photo", "audio": "audio"}

# v1 opened a stop with the first draped photograph at 0.7 and the rest
# hidden, hardcoded in the frontend's TourStore.resetRephotoOpacities().
# v2 authors that per overlay, so writing v1's numbers here means the migrated
# tour opens looking exactly as it did.
_FIRST_IN_WORLD_OPACITY = 0.7
_LATER_IN_WORLD_OPACITY = 0.0


def migrate_v1_to_v2(doc: dict[str, Any]) -> dict[str, Any]:
    """Return a v2 copy of `doc`. A v2 document is returned unchanged."""
    version = doc.get("schemaVersion")
    if version == SCHEMA_VERSION:
        return deepcopy(doc)
    if version != 1:
        raise ValueError(
            f"unsupported schemaVersion {version!r}: this build understands "
            f"1 and {SCHEMA_VERSION}"
        )

    out = deepcopy(doc)
    out["schemaVersion"] = SCHEMA_VERSION
    for stop in out.get("stops", []):
        stop["overlays"] = _migrate_overlays(stop.get("overlays", []))
    return out


def _migrate_overlays(overlays: list[dict[str, Any]]) -> list[dict[str, Any]]:
    in_world_seen = 0
    migrated = []
    for ov in overlays:
        kind = ov.get("kind")
        if kind == "rephoto":
            migrated.append(_rephoto_to_in_world(ov, in_world_seen))
            in_world_seen += 1
        elif kind in _ICON_BY_KIND:
            migrated.append(_to_marker(ov))
        else:
            # Silently dropping an overlay is invisible data loss; a tour
            # would come back from migration quietly shorter.
            raise ValueError(
                f"overlay {ov.get('id')!r} has unknown kind {kind!r}"
            )
    return migrated


def _rephoto_to_in_world(ov: dict[str, Any], index: int) -> dict[str, Any]:
    anchor = ov["anchor"]
    return {
        "id": ov["id"],
        "kind": "image",
        "anchor": _geo_anchor(anchor),
        "display": {
            "mode": "inWorld",
            "opacity": (
                _FIRST_IN_WORLD_OPACITY if index == 0 else _LATER_IN_WORLD_OPACITY
            ),
            "headingDeg": anchor["headingDeg"],
            "widthM": anchor["widthM"],
            "heightM": anchor["heightM"],
        },
        "title": ov["title"],
        "body": ov.get("body"),
        "mediaId": ov.get("mediaId"),
        "credit": _sourced(ov["credit"]),
    }


def _to_marker(ov: dict[str, Any]) -> dict[str, Any]:
    return {
        "id": ov["id"],
        "kind": ov["kind"],
        "anchor": _geo_anchor(ov["anchor"]),
        "display": {"mode": "marker", "icon": _ICON_BY_KIND[ov["kind"]]},
        "title": ov["title"],
        "body": ov.get("body"),
        "mediaId": ov.get("mediaId"),
        "credit": _sourced(ov["credit"]),
    }


def _geo_anchor(anchor: dict[str, Any]) -> dict[str, Any]:
    """Geometry (heading, width, height) belongs to `display` in v2; only
    position survives here. `altitude` is renamed to make its unit and datum
    explicit, and carries the same value."""
    return {
        "type": "geo",
        "lng": anchor["lng"],
        "lat": anchor["lat"],
        "altitudeM": anchor.get("altitude", 0.0),
    }


def _sourced(credit: dict[str, Any]) -> dict[str, Any]:
    """Every v1 credit named an external source, so all of them are `sourced`.
    `original` only becomes reachable once the editor can create media."""
    return {
        "type": "sourced",
        "source": credit["source"],
        "url": credit["url"],
        "license": credit["license"],
        "creator": credit.get("creator"),
    }
```

/**
 * One attribution line for either credit variant.
 *
 * Original work has no URL to link, which is the whole reason the union
 * exists; sourced work links back to where it came from.
 */
export function creditLine(credit: Credit): { attribution: string; url: string | null } {
  if (credit.type === 'original') {
    return { attribution: `${credit.creator} · ${credit.license}`, url: null };
  }
  const who = credit.creator ? `${credit.source} — ${credit.creator}` : credit.source;

}

```markdown
# 0001 — Overlays have three independent axes

Status: accepted, 2026-10-12.

## Problem

In schema v1 an overlay's rendering was dictated by its content type.
`kind: "rephoto"` forced a `geoQuad` anchor and rendered as a plane standing
in the world; every other kind forced a `geo` anchor and rendered as a
clickable marker, enforced by a validator that named both.

The editor has to let an author hang a photograph in the scene **or** pin it
to the street, as a per-item choice. While presentation was welded to content
type, that choice was inexpressible: it would have meant changing what the
item *was* in order to change how it *looked*.

## Considered

**Expand the `kind` list** — `rephoto`, `worldText`, `audioPin`, and so on.
No restructuring, and the validator stays simple. Rejected: the list
multiplies combinatorially, and multiplies again for every new presentation
target. AR alone would roughly double it.

**Carry both presentations at once**, with a viewer-level switch between
"ghosted into the scene" and "pins only". Rejected for now as more authoring
work per item than the author wants, though the split below does not prevent
it: a future `display` variant can carry both.

## Decision

Three independent fields. `kind` (text, image, audio) is what an overlay is,
`anchor` is where it is, `display` (marker, inWorld, ambient) is how it is
drawn. A rephotograph is `kind: "image"` with `display.mode: "inWorld"` —
which is what it always was.

Geometry moved with it. v1's `headingDeg`, `widthM` and `heightM` sat on the
anchor, but they describe how a plane is drawn, not where it is; a marker at
the same spot needs none of them. They now live on `InWorldDisplay`, which is
why switching an overlay between marker and inWorld no longer moves it.

Which combinations are legal lives in one table, `DISPLAY_MODES_BY_KIND`,
rather than a chain of conditionals. A rejection is a *renderer* limitation,
not a limit of the model, and the error message says so.

## Costs

A schema version and a migration, `app.migration.migrate_v1_to_v2`, which
stays in the tree indefinitely: exported bundles in the wild will be v1. Every
read path runs through it, so only v2 exists above the parsing boundary.

The migration is deliberately behaviour-preserving rather than merely valid.
Opacity is written as v1's hardcoded "first at 0.7, rest hidden" so a migrated
tour opens identically, and audio becomes `marker` rather than `ambient`
because nothing autoplayed in v1 — migrating to `ambient` would have started
six narrations playing by themselves.

## How the deferred features land on this

- **AR** is a fourth `display.mode` reading the same anchors, not a parallel
  content hierarchy. This is the decision's main payoff. It is also why
  `altitude` was renamed `altitudeM` and pinned to metres above local ground:
  a phone knows its height above the pavement, not above the ellipsoid, and
  the ambiguity had already put the Fairfax photographs 128 m underground once.
- **Themes** are a tour-level style block; `display` says what an overlay is,
  a theme says how that kind of thing looks across the tour.
- **Omeka** populates the `sourced` credit variant from Dublin Core
  (`dcterms:publisher`, `dcterms:rights`, `dcterms:creator`). The credit union
  was split in the same change because original work — the author's own
  recordings — has no URL, which made v1's single credit shape unsatisfiable
  and would have stopped the editor saving at all.
```
