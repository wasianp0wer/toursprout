# Tour icon and footer credit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A tour can carry a PNG icon that is the favicon of its published site and of Preview, and the viewer footer credits TourSprout.

**Architecture:** `Tour.icon` (schema v5) is a `MediaRef` to a PNG under `media/`. The editor converts any image to a 256×256 PNG in a canvas and uploads it. `publish.py` rewrites the zip's `<link rel="icon">` statically; `ViewerPage` sets the same link at runtime for Preview and restores it on destroy.

**Tech Stack:** FastAPI + pydantic v2 (pytest), Angular 22 signals (Vitest via `ng test`).

**Spec:** `docs/superpowers/specs/2026-11-18-tour-icon-design.md`

## Global Constraints

- Schema version becomes **5**; `_v4_to_v5` changes nothing but `schemaVersion`.
- `Tour.icon` is top-level, optional, a `MediaRef` ending in `.png` (case-insensitive); never inside `theme`.
- Stored icon: PNG, 256×256, image centred with aspect ratio preserved, transparent padding.
- Published `<link>`: `<link rel="icon" type="image/png" href="tour-data/media/<id>">`, id HTML-escaped.
- No icon → published zip byte-identical to today's.
- Footer copy exactly `Powered by TourSprout`, `href="https://github.com/wasianp0wer/toursprout"`, `target="_blank" rel="noopener"`, after the attribution loop.
- No new dependencies (backend or frontend).
- Commands: `make backend-test`, `make frontend-test`, `make lint`, `make build` from the worktree root.

## Review Focus

1. **An imported bundle whose `icon` id contains `"` or `<`** — the published `index.html` must not gain markup. Task 2 adds `test_icon_href_is_escaped`.
2. **`/edit` → `/view` → `/edit` round-trip** — the editor's tab must be back on the default icon. Task 4 adds `restores the original favicon when destroyed`.
3. **A bundle naming an icon that is not in `media/`** — import must report it missing like any other ref. Task 1 adds `test_referenced_media_includes_the_icon` (the import path already consumes `referenced_media`).
4. **A non-square or tiny image (e.g. 1000×200 or 16×16)** — must come out 256×256, centred, not stretched. Task 3 pins the draw rectangle in `fitSquare`.
5. **A file the browser cannot decode (e.g. a `.txt` renamed `.png`)** — the dialog shows an error and the document is untouched. Task 3 adds `shows an error and leaves the tour alone when the image cannot be read`.
